# Картограф – десктопный конструктор карт

[![GitHub package version](https://img.shields.io/github/package-json/v/Danila060606/TMAP)](https://github.com/Danila060606/TMAP/packages)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Картограф** – это десктопное приложение для визуализации и редактирования карт на основе OpenStreetMap. Оно позволяет создавать маршруты, добавлять остановки, настраивать логотипы и управлять данными через GitHub.

Приложение разработано на **Electron**, использует **Leaflet** для отображения карт и работает с локальными GTFS-файлами, а также поддерживает авторизацию через `users.json`, хранящийся в репозитории GitHub.

⚙️ Настройка и конфигурация
1. Файлы данных на GitHub
Приложение ожидает, что в корне репозитория (или в папке gtfs/) находятся следующие файлы:

stops.txt – список остановок в формате GTFS.

users.json – список пользователей для авторизации (см. раздел «Управление пользователями»).

Пути к этим файлам задаются в index.html через переменные:

javascript
const GITHUB_USER = 'Danila060606';
const GITHUB_REPO = 'TMAP';
const GITHUB_BRANCH = 'main';
При необходимости вы можете изменить эти значения в коде.

2. Авторизация и GitHub Token
Для сохранения логотипов и редактирования пользователей требуется Personal Access Token (классический) с правами repo и write:packages.

Получить токен можно здесь:
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)

При первом сохранении логотипов или открытии админ-панели программа запросит этот токен.

3. Файл users.json
Пример структуры:

json
[
  {
    "id": 1,
    "username": "admin",
    "password_hash": "$2b$10$...",
    "full_name": "Administrator",
    "role": "admin"
  },
  {
    "id": 2,
    "username": "user1",
    "password_hash": "$2b$10$...",
    "full_name": "Иван Петров",
    "role": "user"
  }
]
Пароли хранятся в виде bcrypt-хешей. Для генерации хеша используйте скрипт hash.js (находится в папке hash-gen/).

👥 Управление пользователями
Если вы вошли как пользователь с ролью admin, в верхней панели появится кнопка «Администрирование». Она открывает модальное окно, где вы можете:

просматривать всех пользователей;

редактировать логины, ФИО и роли;

удалять пользователей;

добавлять новых пользователей (с автоматическим хешированием пароля через bcrypt).

Все изменения сохраняются непосредственно в users.json на GitHub (через GitHub API).

🖼️ Экспорт и импорт логотипов
Логотипы – это маркеры, которые вы размещаете на карте и настраиваете (размер, фон, прозрачность).

Сохранить логотипы – генерирует PNG-изображения для каждого логотипа и загружает их в папку LOGOT на GitHub, а также обновляет logos_backup.json с настройками.

Загрузить логотипы – позволяет восстановить логотипы из локального JSON-файла (например, ранее сохранённого).

Для сохранения на GitHub требуется ввести токен доступа.

🗺️ Основные возможности
Интерактивная карта – на основе OpenStreetMap с кастомизируемым стилем (CartoDB Light).

Поиск и отображение остановок – загрузка из stops.txt с отображением типа транспорта (автобус, трамвай, метро и т.д.).

Рисование линий и полигонов – создание маршрутов с возможностью задания номера.

Редактирование свойств объектов – изменение цвета, толщины, прозрачности, а также добавление названий.

Сохранение и загрузка маршрутов – в localStorage браузера.

Экспорт в GeoJSON, PNG, PDF – выгружайте карту вместе со всеми объектами.

Плавающая панель остановок – перетаскивается мышью.

Сворачиваемая панель свойств – для экономии места.
